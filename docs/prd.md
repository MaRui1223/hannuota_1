# 需求文档

## 1. 应用概述

### 1.1 应用名称
汉诺塔挑战

### 1.2 应用描述
本应用为汉诺塔游戏的网页版本，用户通过点击交互方式移动圆盘，完成从左柱到右柱或中柱的搬运挑战。应用包含静态界面展示、核心交互逻辑、规则校验、步数统计、难度选择、动画过渡、重置功能、响应式布局适配、视觉升级和音效系统。

## 2. 页面结构与功能说明

### 2.1 页面结构

应用包含单个游戏页面，结构如下：

```
游戏页面
├── 标题区域
│   ├── 游戏标题「汉诺塔挑战」
│   ├── 难度选择按钮组
│   ├── 步数计数器
│   ├── 音效开关按钮
│   └── 重新开始按钮
└── 游戏区域
    ├── 左柱子（柱A）
    ├── 中柱子（柱B）
    ├── 右柱子（柱C）
    └── 底座
```

### 2.2 功能说明

#### 2.2.1 标题区域

**游戏标题**
  - 显示文本「汉诺塔挑战」
  - 位于页面上方居中位置
  - 手机端字号响应式缩小

**难度选择按钮组**
  - 显示4个按钮，分别对应3、4、5、6个圆盘
  - 按钮组采用segmented control风格
  - 当前选中的难度按钮高亮显示
  - 点击任一按钮切换难度，触发游戏重置
  - 位于标题下方或右侧
  - 触控尺寸≥32px

**步数计数器**
  - 显示当前移动步数
  - 初始值为0
  - 每次合法移动后自动+1
  - 位于标题区域

**音效开关按钮**
  - 显示音量图标，支持开启/关闭状态切换
  - 点击切换音效开关状态
  - 默认开启
  - 触控尺寸≥32px
  - 位于标题区域

**重新开始按钮**
  - 显示文本「重新开始」
  - 点击后触发重置功能
  - 位于标题区域
  - 触控尺寸≥32px

#### 2.2.2 游戏区域

**布局**
  - 游戏区域在页面居中显示
  - 包含3根垂直柱子（左、中、右），柱子间距通过CSS变量--tower-gap控制（手机端12px、sm断点32px、md断点48px）
  - 底部有底座连接三根柱子
  - 棋盘容器max-width:100%，防止圆盘组超出容器
  - 柱子使用grid布局，三列等宽，列间距为--tower-gap

**柱子**
  - 视觉样式：深棕色圆柱体
  - 高度随vw缩放，足以容纳6个圆盘堆叠
  - 三根柱子高度一致
  - 整根柱子为点击热区，支持触摸交互
  - 柱子通过grid布局定位，列间距与圆盘层共用CSS变量--tower-gap

**圆盘**
  - 数量：根据难度选择为3、4、5或6个
  - 形状：圆角矩形
  - 宽度：以柱子槽位（柱间距基准容器）为基准，最大圆盘宽度≤槽位的90%，最小圆盘宽度为30%（屏幕<480px时自动缩小至24%），中间线性递减（例如5盘：30%/45%/60%/75%/90%）
  - 高度：clamp(12px, 3vh, 24px)，移动端不过厚、桌面不过薄
  - 层距：固定2px，避免视觉粘连
  - 视觉样式：渐变色 + 阴影 + 顶部高光条，增强立体感
  - 颜色：支持6种颜色映射，每个圆盘颜色不同，便于区分
  - 初始状态：所有圆盘全部堆叠在左柱子（柱A）上，大圆盘在下、小圆盘在上
  - 选中状态：上浮 + 白色描边 + 发光特效（glow shadow）
  - 渲染方式：使用统一坐标系绝对定位，left值通过calc公式计算列中心位置（列中心 = i×(列宽+gap) + 列宽/2，其中列宽=(100%-2×gap)/3，gap为CSS变量--tower-gap），配合translateX(-50%)实现圆盘严格居中对齐柱子中心线，bottom值根据层级×(圆盘高度+层距)计算
  - z-index：按堆叠层级递增，顶部圆盘z-index最高
  - 点击热区：圆盘pointer-events仅作用于自身可见区域（热区=圆盘可见尺寸，无透明padding误触），点击圆盘等价于点击其所在柱子（复用TOWER_CLICK统一入口）
  - 移动动画：圆盘移动时添加平滑的CSS过渡动画

**底座**
  - 连接三根柱子的底部横向结构
  - 视觉上与柱子形成整体

**整体风格**
  - 简约扁平化设计
  - 背景色柔和，不干扰游戏元素

#### 2.2.3 交互功能

**选中圆盘**
  - 用户点击某柱子（整根柱子为热区）或点击圆盘（圆盘热区=可见尺寸）
  - 该柱子顶端圆盘进入选中状态，视觉上上浮 + 白色描边 + 发光特效
  - 点击已选中的柱子可取消选中
  - 点击柱子上的非顶端圆盘无效

**移动圆盘**
  - 选中圆盘后，点击目标柱子
  - 系统执行规则校验
  - 校验通过：圆盘以平滑动画移动到目标柱子顶端，步数+1，取消选中状态，播放移动音效（短促清脆音）
  - 校验失败：圆盘不移动，目标柱子播放轻微震动动画，显示Toast提示「无法放置：大盘不能压小盘」（自动消失），播放非法移动低沉提示音，保持选中状态

**难度切换**
  - 点击难度选择按钮组中的任一按钮
  - 切换到对应圆盘数量（3/4/5/6个）
  - 自动触发游戏重置：所有圆盘归位到左柱子（柱A），步数计数器清零，取消任何选中状态

**音效开关**
  - 点击音效开关按钮
  - 切换音效开启/关闭状态
  - 音效关闭时，所有音效不播放
  - 音效开启时，根据交互触发对应音效

**重置游戏**
  - 点击「重新开始」按钮
  - 所有圆盘归位到左柱子（柱A）
  - 步数计数器清零
  - 取消任何选中状态
  - 保持当前难度不变

**游戏胜利判定**
  - 当所有圆盘按规则移动到右柱子（柱C）或中柱子（柱B）时
  - 播放通关胜利音效（琶音）
  - 显示精美胜利弹窗，包含以下元素：
    + 装饰性光晕背景
    + 奖杯徽章
    + 步数统计小卡片：显示实际步数和理论最少步数（2^n - 1，n为当前圆盘数量）
    + 效率评价：实际步数等于理论最少步数时显示「完美通关」，否则显示效率百分比
    + 渐变主按钮「再玩一次」，点击后重置当前难度的游戏

## 3. 业务规则与逻辑

### 3.1 数据结构

使用数组模拟栈结构存储圆盘状态：
  - `towerA`：左柱子的圆盘栈，初始值根据难度为 `[n, n-1, ..., 2, 1]`（n为圆盘数量）
  - `towerB`：中柱子的圆盘栈，初始值为 `[]`
  - `towerC`：右柱子的圆盘栈，初始值为 `[]`

**数据说明**：
  - 数字代表圆盘大小（数字越大，圆盘越大）
  - 数组末尾为栈顶，即最上层圆盘
  - 数组开头为栈底，即最下层圆盘
  - 圆盘大小范围为1~6，根据难度选择动态调整

### 3.2 渲染逻辑

根据数据结构动态渲染圆盘在柱子上的堆叠效果：
  - 遍历每个柱子的数组，按顺序从下到上渲染圆盘
  - 圆盘使用统一坐标系绝对定位，left值通过calc公式计算：列中心 = i×(列宽+gap) + 列宽/2，其中列宽=(100%-2×gap)/3，gap为CSS变量--tower-gap（手机端12px、sm断点32px、md断点48px），配合translateX(-50%)实现圆盘严格居中对齐柱子中心线
  - bottom值根据层级×(圆盘高度+层距)计算，圆盘高度为clamp(12px, 3vh, 24px)，层距固定2px
  - 圆盘宽度以柱子槽位为基准，最大圆盘宽度≤槽位的90%，最小圆盘宽度为30%（屏幕<480px时通过CSS变量--disk-min-pct自动缩小至24%），中间线性递减
  - 圆盘视觉样式：渐变色 + 阴影 + 顶部高光条
  - 圆盘颜色与数字大小对应（每个数字固定一种颜色，支持6种颜色映射）
  - 圆盘z-index按堆叠层级递增，顶部圆盘z-index最高
  - 圆盘pointer-events仅作用于自身可见区域，点击圆盘等价于点击其所在柱子
  - 选中状态的圆盘：上浮 + 白色描边 + 发光特效
  - 圆盘移动时，left和bottom属性添加CSS过渡动画

### 3.3 规则校验逻辑

移动圆盘前必须执行以下校验：

**基础校验**
  - 只能移动柱子最顶端的圆盘
  - 源柱子不能为空

**核心规则校验**
  - 如果目标柱子为空，允许移动
  - 如果目标柱子非空，且目标柱子顶端圆盘 < 被移动圆盘，禁止移动
  - 如果目标柱子非空，且目标柱子顶端圆盘 > 被移动圆盘，允许移动

**校验失败处理**
  - 圆盘不移动
  - 目标柱子播放轻微震动动画
  - 显示Toast提示「无法放置：大盘不能压小盘」，Toast自动消失
  - 播放非法移动低沉提示音（音效开启时）
  - 保持选中状态

**校验通过处理**
  - 更新数据数组：从源柱子栈顶移除圆盘，添加到目标柱子栈顶
  - 圆盘以平滑动画移动到目标位置
  - 重绘UI
  - 步数计数器+1
  - 播放移动音效（短促清脆音，音效开启时）
  - 取消选中状态

### 3.4 步数统计逻辑

  - 步数计数器初始值为0
  - 每次合法移动后，步数+1
  - 重置游戏或切换难度时，步数清零

### 3.5 难度切换逻辑

  - 用户点击难度选择按钮组中的按钮
  - 更新当前难度为对应圆盘数量（3/4/5/6）
  - 触发游戏重置逻辑
  - 更新难度按钮组的高亮状态

### 3.6 重置逻辑

  - 数据结构恢复初始状态：`towerA = [n, n-1, ..., 2, 1]`（n为当前难度圆盘数量）、`towerB = []`、`towerC = []`
  - 步数计数器清零
  - 取消任何选中状态
  - 重绘UI

### 3.7 游戏胜利判定逻辑

  - 每次移动后检查 `towerB` 或 `towerC` 的圆盘数量是否等于当前难度的总圆盘数
  - 如果满足条件，播放通关胜利音效（琶音，音效开启时）
  - 显示精美胜利弹窗，包含以下内容：
    + 装饰性光晕背景
    + 奖杯徽章
    + 步数统计小卡片：显示实际步数和理论最少步数（2^n - 1，n为当前圆盘数量）
    + 效率评价：实际步数等于理论最少步数时显示「完美通关」，否则显示效率百分比（理论最少步数 / 实际步数 × 100%）
    + 渐变主按钮「再玩一次」，点击后触发重置逻辑

### 3.8 音效逻辑

  - 音效开关默认开启
  - 音效开启时，根据交互触发对应音效：
    + 合法移动：播放短促清脆音
    + 非法移动：播放低沉提示音
    + 通关胜利：播放琶音
  - 音效关闭时，所有音效不播放
  - 音效模块独立为soundEffects.ts，由视图层根据状态变化触发

### 3.9 响应式适配逻辑

  - 柱子间距通过CSS变量--tower-gap控制：手机端12px、sm断点32px、md断点48px
  - 柱子grid布局与圆盘层共用--tower-gap变量，确保圆盘严格居中对齐柱子中心线
  - 圆盘left值通过calc公式计算：列中心 = i×(列宽+gap) + 列宽/2，其中列宽=(100%-2×gap)/3，配合translateX(-50%)实现居中
  - 圆盘高度clamp(12px, 3vh, 24px)，移动端不过厚、桌面不过薄
  - 圆盘层距固定2px
  - 圆盘最小宽度通过CSS变量--disk-min-pct控制：屏幕≥480px时为30%，屏幕<480px时自动缩小至24%
  - 棋盘容器max-width:100%，防止圆盘组超出容器
  - 手机端标题字号、控件间距响应式缩小
  - 整根柱子为点击热区，圆盘热区=可见尺寸，触摸热区足够大
  - 顶部按钮（难度/重开/音效开关）触控尺寸≥32px

### 3.10 代码整理

  - 逻辑与视图分离：hanoiData.ts 纯数据/规则、gameReducer.ts 状态机已分离
  - 音效独立为soundEffects.ts模块，由视图层根据状态变化触发

## 4. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 数据结构为空数组 | 柱子上不渲染圆盘 |
| 数据结构包含非法值 | 忽略非法值或显示错误提示 |
| 页面尺寸过小 | 游戏区域等比缩放，棋盘容器max-width:100%防止溢出 |
| 屏幕<480px | 圆盘最小宽度自动缩小至24%，高度上限缩小，防止挤压变形 |
| 点击柱子上的非顶端圆盘 | 无效操作，不触发选中 |
| 点击空柱子尝试选中 | 无效操作，不触发选中 |
| 选中状态下点击同一柱子 | 取消选中状态 |
| 选中状态下点击空柱子 | 执行移动操作 |
| 违反规则的移动 | 目标柱子播放震动动画，显示Toast提示，播放非法移动音效，圆盘不移动 |
| 重复点击重新开始按钮 | 每次点击均触发重置逻辑 |
| 游戏进行中切换难度 | 自动触发重置逻辑，步数清零，圆盘归位 |
| 胜利弹窗显示时继续操作 | 弹窗遮罩阻止游戏区域交互 |
| 浏览器不支持Web Audio API | 音效功能不可用，不影响游戏核心功能 |
| 音效开关关闭 | 所有音效不播放 |
| 圆盘点击热区误触 | 圆盘pointer-events仅作用于可见区域，无透明padding误触 |
| 柱子间距与圆盘定位不一致 | 柱子grid与圆盘层共用CSS变量--tower-gap，确保对齐 |

## 5. 验收标准

1. 打开页面，页面居中显示游戏区域，包含3根深棕色垂直柱子和底座，柱子间距在手机端为12px、sm断点为32px、md断点为48px，顶部显示标题「汉诺塔挑战」、难度选择按钮组（3/4/5/6）、步数计数器（显示0）、音效开关按钮（默认开启）和「重新开始」按钮
2. 默认难度为5个圆盘，左柱子（柱A）上堆叠5个圆盘，从下到上宽度线性递减（90%/75%/60%/45%/30%），圆盘高度为clamp(12px, 3vh, 24px)，层距固定2px，圆盘具有渐变色 + 阴影 + 顶部高光条，圆盘严格居中对齐柱子中心线
3. 调整浏览器窗口宽度，游戏区域随视口宽度自适应缩放，棋盘容器max-width:100%防止溢出，屏幕<480px时圆盘最小宽度自动缩小至24%
4. 在手机竖屏模式下打开页面，标题字号、控件间距响应式缩小，柱子间距为12px，顶部按钮触控尺寸≥32px，整根柱子为点击热区，圆盘热区=可见尺寸
5. 点击左柱子或点击顶端圆盘，顶端圆盘进入选中状态，视觉上上浮 + 白色描边 + 发光特效
6. 点击中柱子，圆盘以平滑动画移动到中柱子顶端，圆盘严格居中对齐柱子中心线，步数计数器显示1，播放短促清脆音
7. 尝试将大圆盘放在小圆盘上，目标柱子播放震动动画，显示Toast提示「无法放置：大盘不能压小盘」，播放低沉提示音，圆盘不移动
8. 按规则将所有圆盘移动到中柱子（柱B），系统播放琶音，显示精美胜利弹窗，包含装饰性光晕背景、奖杯徽章、步数统计小卡片（实际步数/理论最少步数）、效率评价（完美通关或效率百分比）、渐变主按钮「再玩一次」
9. 点击胜利弹窗中的「再玩一次」按钮，所有圆盘归位到左柱子，步数计数器清零，保持当前难度（5个圆盘）
10. 点击音效开关按钮，音效关闭，再次移动圆盘时不播放音效
